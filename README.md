# Working with Objects

This project is part of the **JavaScript - The Complete Guide 2025 (Beginner + Advanced)** collection.  
It introduces practical use of JavaScript objects by building and filtering a list of items, such as movies or tasks.

## 📌 Features
- Add new items to a list using JavaScript objects
- Filter the list based on custom object properties
- Render dynamic content to the DOM
- Clean and simple user interface

## 🛠️ Tech Stack
- **Languages**: HTML, CSS, JavaScript (ES6+)
- **Styling**: Basic CSS
- **Tools**: VS Code, Git, GitHub

## 🚀 Live Demo
[Demo](https://flavia3107.github.io/javascript-objects/)

## 📚 Learning Goals
- Understand how to create and manage JavaScript objects
- Learn object arrays and how to loop through them
- Practice filtering and rendering lists based on object data
- Improve structuring of data-driven DOM updates
